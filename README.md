# Fedora Linux

Practical Fedora Linux troubleshooting, automation, and system administration projects.

This repository documents hands-on Linux projects and troubleshooting cases performed on Fedora Linux.

## Projects

### OBS Virtual Camera

Troubleshooting and configuring OBS Virtual Camera on Fedora using `v4l2loopback`, AKMOD, MOK module signing, and Secure Boot.

### ATK/VXE Web Driver

Troubleshooting WebHID and HIDRAW access for ATK/VXE mouse configuration tools using udev rules and POSIX ACLs.

### Automatic AC Power Profile

Automatically switches between Performance and Balanced power profiles based on the laptop's AC power state using Bash, systemd, udev, and the Power Profiles D-Bus API.
